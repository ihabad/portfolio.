# Ihab Abou Diab - Financial Crime Operations Portfolio

## GitHub Pages setup

Upload these files to the root of your GitHub repository:

- `index.html`
- `Ihab_Abou_Diab_Resume.pdf`
- `.nojekyll`

`README.md` is optional for the website but useful for the repository.

### Publish

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch.
6. Select **/(root)**.
7. Save.

The portfolio is self-contained in `index.html`. The Resume viewer works inside the page, and the PDF is also included separately.
